Official repository for **TikTok-ViralScore**, a comprehensive multimodal dataset designed for predicting short-video virality scores using Machine Learning & Computer Vision.

---

## 📌 Overview

Predicting short-video popularity is a critical task in digital content optimization and social media analytics. **TikTok-ViralScore** provides a curated benchmark dataset containing multi-modal features extracted from short video clips.

* **Total Samples:** 7,046 TikTok videos
* **Modalities:** Visual Features, Audio Features, Text Metadata, and Temporal Engagement Data
* **Task:** Regression & Classification of Viral Potential (Viral Score)
